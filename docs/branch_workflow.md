# Branch workflow

Use one branch per methodological hypothesis.

## Naming
- `feat/<method-name>` for new methods.
- `exp/<date>_<pilot-name>` for quick pilot iterations.
- `fix/<issue-name>` for bug fixes.

## Minimum merge evidence
- Quantitative comparison against baseline in `reports/`.
- Pilot plots saved under `experiments/`.
- Relevant tests passing.
- Clear note of failure modes, if any.
